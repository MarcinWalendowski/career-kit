## Hard invariants

   usually not the tool's default, and the wrong address cannot be taken back.
2. **Attach `{{profile.attachments.cv}}`.**

3. **Never double-send.** Run `gate check`, then `gate claim` immediately before acting. If either
   exits 3, stop and report. There is no retry with different arguments.

   {{#if rules.company.followups_allowed}}Follow-ups are allowed under
   `company.maxApplications: {{rules.company.maxApplications}}`.{{/if}}
   {{#unless rules.company.followups_allowed}}No follow-up, no correction, no second send, ever. If

5. **Banned in every artifact:** {{#each rules.content.banned_characters}}`{{.}}` {{/each}}
   {{#each rules.content.banned_phrases}}"{{.}}" {{/each}}

## The dedupe protocol, and it runs before any research

1. Query the Sent folder for the company domain and every alternate brand domain. Count the results.
2. ```
   gate check --id <id> --channel <channel> --sent-check <count> \
              --sent-check-query "<the query you ran>" --identity-domain <domain>
   ```
   Exit 3 means stop. `--sent-check` is required: an unknown count blocks, it does not pass.
3. Research, draft, get approval.
4. ```
   gate claim --id <id> --channel <channel> --route <url>
   ```
   **immediately before acting**, not at the top of the task. The claim expires in
   {{rules.lease.seconds}} seconds and `record` rejects a stale token. The gap between the check and
   the act is the entire window in which a duplicate is born.
5. Act.
6. ```
   gate record --id <id> --token <token> --status sent \
               --sent-at <transport timestamp> --sent-at-source transport [--receipt <path>]
   ```
   Record first, report second. A send that is not recorded is a future double-send.

A lease held by another process (`pending-elsewhere`) means somebody else is mid-flight on your
target. Stop and ask. So does a browser tab already open on your apply URL.

## Channel mechanics

**Email.** Account `{{profile.mail.account}}`, from name `{{profile.mail.from_name}}`, attachment
`{{profile.attachments.cv}}`. Subject line: short, specific, names the role and the strongest hook.

**Form and ATS.** Open the claimed route in a new tab, never an existing one. Upload the CV. Answer
free text in the voice above. Submit only if the gate allowed it. Capture a receipt to a durable
path and pass it to `record`: a screenshot under a system temp directory is reaped, and it is the
only proof the submit happened. Never trigger a JavaScript alert or confirm dialog.
