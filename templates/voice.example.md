# Voice

Copy this to `$CAREER_HOME/voice.md` and replace every example line. The persona
here is fictional, so anything left unedited is obvious in a draft.

This file governs **everything written in your name**: application emails,
replies, form free-text, LinkedIn and social copy. It is not a style guide you
consult. `career-apply` compiles it into `outputs/brief.md` on every run, so
editing this file changes the next draft.

Two things make a voice file work, and both are easy to skip:

1. **Say what the rule is, then what it cost.** "No em dash" is a preference.
   "No em dash, because it reads as an AI tell and this copy has to sound like a
   person" is a rule that survives someone disagreeing with it.
2. **Fill in Provenance.** See the bottom of this file for why that section is
   not decoration.

## Register

How your sentences are built. Be specific enough that a draft can be checked
against it, not just admired.

- Plain sentences of 15 to 20 words. One idea per sentence. Ordinary words.
- Say what a thing **is** before what it is made of. "Analytical Engine is a
  machine that computes any function you can write down" beats a list of parts.
- Lead with outcomes, not the stack. Name at most one technology per sentence,
  and only when it proves something surprising.
- Contractions throughout. Active first person: "I built", "I shipped".
- Short paragraphs, two to four sentences, blank line between.
- Undersell. Understatement is the register: "it worked out well" beats
  "a transformative result".

## Hard limits

Numbers, so a draft can be measured rather than argued about.

- Application email: max **2 sections**, **5 to 8 sentences** total. Greeting,
  the one-line close and the sign-off do not count.
- Replies: **15 to 40 words**. Do not pad a reply into a pitch.
- Cold outreach with a CV attached: 150 to 450 words. Aim low.
- Comments on social posts: treat as a reply, not as a post.

## Openings

- First contact: `Hi <First>,` and a greeting beat. "Hi Charles, nice to meet
  you."
- Reply or warm thread: `Hey <First>,`
- **The second line is always the connective tissue**, before anything about
  yourself: how you got here. "We overlapped at the Analytical Society." /
  "Thanks again for the note last week."
- Never "I hope this email finds you well."

## Closings

- The ask is plain and one line: "I'm currently looking for new roles."
- Name the attachment explicitly: "My CV is attached with the full details."
- Low-pressure close: "Happy to chat if you see a match here."
- Sign-off: `Best,` plus full name on first contact, `Best,` plus first name on
  replies. Never "Warm regards", never "Sincerely".

## Negative rules

One line each. **Date each one and record what it cost**, because that is the
part that stops the rule being deleted six months from now by someone who finds
it inconvenient.

- **Never the em dash character.** (2026-01-14) It reads as an AI tell and
  undermines copy meant to sound like a person. Re-punctuate, never reword.
- **Never stack jargon.** (2026-02-02) A draft packing five technologies into
  one 60-word sentence was rejected as unreadable. Name one thing at a time.
- **Never tell the recipient what their own product lacks.** (2026-02-02) It
  reads as a pitch deck and it is usually wrong.
- **No corporate filler:** circle back, synergies, leverage, touch base.
- **Never claim something you have not done**, including softly. "I contributed
  to" when that is the truth. Admitting a gap plainly is what makes the
  confident parts land.

This section is the reason the file is worth anything. A voice file records a
judgement that took several rounds of "no, still not right" to land, and none of
that is visible in the finished text. Without provenance, the next agent that
thinks it knows better rewrites the file in one pass and the three rounds are
gone.

Update all four lines whenever the voice is re-derived. If you wrote this by
hand instead of deriving it, say so: "written by hand, no sample" is useful
information, not an admission.
